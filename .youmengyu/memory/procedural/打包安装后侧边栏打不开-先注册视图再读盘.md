# 打包安装后侧边栏打不开

教训（2026-11-25）：显式 `activationEvents` 只有 `onStartupFinished` 时，安装后恢复侧边栏会赶在视图提供器注册之前。记忆读盘、数字人导入若堵在 `registerWebviewViewProvider` 前面，视图会停在没有提供器。页面不要再用 QuickPick、输入框、文件对话框；确认也放在同一个 Webview 里。

- 激活事件带上 `onView:aimemory.panel`
- `new MemoryStore({ defer: true })`，先注册再 `bindWorkspace()`
- 新建 / 提炼 / 画像 / 导入 / 删除确认都是面板标签，不另开窗口
- 侧边栏收起时，非 Cursor 先 `workbench.action.focusSideBar`，再 `workbench.view.extension.aimemory`。Cursor 不要先 focus 主侧边栏，那会切回 Agent，记忆页变成空白
- Cursor 的活动栏 webview 经常不绘制。点开插件时用 `createWebviewPanel('aimemory.editor')` 在编辑区打开同一页面，并在下一拍重设 html
