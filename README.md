# 游梦鱼·长记忆 (AI Memory for Git Repos)

给每个 Git 仓库一份**可长期积累、可注入 AI 编程助手**的本地长记忆：事实化存储、画像注入、语义重排检索、版本链与关系图、空间分区，**零依赖、本地优先、随 Git 共享**。

记忆数据**跟着仓库自身存储**：默认落在仓库根的 `.youmengyu/memory/long-memory/`，**每条记忆一个 JSON 文件**（文件名是内容哈希），提交进 Git 即全团队、全 AI 共享同一份记忆；不同终端改不同条目不会互相冲突。

## 它解决什么问题

AI 编程助手（Copilot / Cursor / Cline / Claude Code / 各类 Agent）每次进入仓库都是"失忆"的：同样的坑反复踩，同样的约定反复交代。本插件把仓库的**教训、决策、架构、偏好、关键 Bug 与事实**沉淀为结构化记忆，自动生成 AI 可读的注入块（`AGENTS.md` 等），让任何 AI 助手开工前先读完仓库记忆。

## 核心特性

- **记忆条目**：标题 + 正文 + 标签（教训/决策/架构/偏好/Bug/工作流/事实）+ 重要性 1-5 + 置顶 + 来源（文件:行 / git 提交）+ 命中计数
- **事实化存储**：正文自动切成原子事实短句，检索与画像优先命中这些短句，长文不再"糊成一团"
- **仓库画像**：静态画像（置顶 + P5）与动态画像（近 30 天有改动或高命中）整段注入，AI 第一眼读到最高优先约定
- **语义重排检索**：关键词命中 + 中文二元组相似度 + 重要性 + 置顶 + 新鲜度 + 命中次数加权排序，零外部依赖；支持按标签、空间、排序方式过滤
- **版本链**：内容被改写前自动留档（最多 10 个历史版本），随时可回溯"这条约定原来怎么写"，也能一键回滚
- **关系图**：按向量相似度 + 共享标签自动发现相关记忆，详情抽屉里可直接跳转
- **记忆空间**：按项目/主题分区（如 前端 / 后端 / 发布），面板、侧栏、检索都能按空间筛选
- **遗忘与过期**：删除前可先「归档」留档并随时恢复；设置过期日期后自动退出检索与注入
- **记忆面板**：卡片网格 + 筛选排序 + 仓库画像条 + 详情抽屉（事实 / 关系 / 版本 / 元数据）+ 行内编辑，深色浅色主题自适应
- **侧栏浏览**：按标签分组；QuickPick 快速搜索（`Ctrl+Alt+M`）
- **Git 提炼**：多选最近提交，一键提炼为记忆草稿（可统一指定空间）
- **注入生成**：标记对安全写入 `AGENTS.md` / `CLAUDE.md` / `.cursorrules` / `.github/copilot-instructions.md`，不动文件其余内容
- **批量导入**：JSON 一键合并（同内容自动去重）；也可多选 `md` / `txt` 文档批量入库并自动事实化
- **数字人记忆打通**：一键（或激活时自动）把游梦鱼数字人 `.youmengyu/memory/**` 里的身份、教训、流程、架构记忆导入到「数字人」空间，同内容幂等合并不重复
- **按条目存储**：`<仓库>/.youmengyu/memory/long-memory/<id>.json`，原子写入（tmp+rename）；命中计数等易变数据放 `.local/hits.json` 并由嵌套 `.gitignore` 排除，不进 Git 也就不会产生同步冲突
- **平滑升级**：0.1-0.3 的旧单体 `memories.json`（`.aimemory/` 或 `.youmengyu/` 根）首次启动自动拆成按条目存储，迁移成功后删除旧文件，不留重复数据

## 使用

安装并打开工作区后即自动开始，不必再点命令：

- **记住当前 Agent 的全部对话**：读取本机 Cursor 里该仓库的 Agent 记录，每段对话收成一条可检索记忆（空间「agent」，不挤进注入块）
- **学习并强化长记忆**：从对话里抽出「必须 / 禁止 / 约定 / 教训」等句子写入长记忆；同一约定再次出现时重要性 +1，直到 P5 进入仓库画像
- **自动辅助编程**：把长记忆写进 `AGENTS.md`（标记对之外的项目规则保持不动）。Agent 开工先读到这些约定，能确定的直接执行

1. 打开任意工作区，`Ctrl+Alt+Shift+M` 或侧栏 ➕ 添加记忆（编辑器选中文本可直接入库，流程里可选标签、重要性、空间）
2. `Ctrl+Alt+M` 搜索记忆；侧栏按标签浏览，右键编辑/置顶/归档/移动空间/查看详情/删除
3. 「游梦鱼·长记忆: 打开记忆面板」查看全部记忆：搜索、按标签与空间筛选、切换排序、看仓库画像、行内编辑与详情
4. 命令面板执行「游梦鱼·长记忆: 生成 AI 助手注入块」，在 `AGENTS.md` 中生成标记对区块
5. 「游梦鱼·长记忆: 复制全部记忆上下文」可把记忆粘贴给任何 AI 对话
6. 「游梦鱼·长记忆: 从最近 Git 提交提炼记忆」把 commit message 变成长期教训
7. 「游梦鱼·长记忆: 查看仓库画像」快速确认哪些约定会被 AI 优先读到
8. 「游梦鱼·长记忆: 从文件批量导入记忆」把仓库里的设计文档、复盘笔记批量变成记忆
9. 「游梦鱼·长记忆: 导入游梦鱼数字人记忆」把数字人的身份、教训、流程一次性搬进当前仓库（`aimemory.youmengyuAutoImport` 开启时激活后自动做）

## 注入块示例

```markdown
<!-- aimemory:start -->

# 游梦鱼·长记忆 · my-repo

> 本区块由「游梦鱼·长记忆」插件自动维护，请勿手动编辑标记对之间内容。

## 仓库画像（最高优先）

- ⭐**发布门禁**（工作流·P5）: 发布前必须跑 npm run asaitest 与 lint，缺一不可
  - 事实: 发布前必须跑 npm run asaitest
  - 事实: 发布前必须跑 lint

## 近期动态画像

- **App 端禁用 vh 单位**（教训·P4）: uni-app x App 端 CSS 禁用 vh/%，改用 flex 布局

## 长期记忆条目

- **构建产物不再提交**（决策·P3）: dist 与 node_modules 一律走 .gitignore
<!-- aimemory:end -->
```

## 配置

| 配置 | 默认 | 说明 |
|------|------|------|
| `aimemory.storageDir` | `.youmengyu/memory/long-memory` | 记忆存储目录（相对仓库根，每条一个 JSON） |
| `aimemory.injectTargets` | `["AGENTS.md"]` | 注入目标文件（可多选） |
| `aimemory.maxInjectEntries` | `60` | 注入块最多条数（画像优先，其余按重要性补齐） |
| `aimemory.autoInject` | `true` | 安装后自动把长记忆写入注入文件，供当前 Agent 开工读取；内容未变不写盘 |
| `aimemory.autoAgentMemory` | `true` | 自动记住当前工作区 Agent 对话，并提炼、强化长记忆。关闭则停止监听 |
| `aimemory.youmengyuRoot` | `D:/Web/asaiwebagent` | 游梦鱼数字人仓库根目录（数字人记忆导入的数据源） |
| `aimemory.youmengyuAutoImport` | `true` | 激活时自动导入数字人记忆（同内容幂等合并，仅新增时提示） |

## 隐私

所有记忆只存在你的仓库里，不上传任何服务器；导出/导入 JSON 随意迁移。
